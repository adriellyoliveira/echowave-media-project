## EchoWave Media 

EchoWave Media é um projeto fictício de um estúdio de produção audiovisual, desenvolvido com foco na prática de desenvolvimento front-end a partir de um protótipo no Figma.

O objetivo do projeto é simular um site institucional moderno, apresentando os principais serviços de um estúdio criativo, como produção de vídeos, edição e criação de conteúdo visual. 

A aplicação foi construída utilizando HTML e CSS, com foco em boas práticas de estruturação semântica, organização de layout e responsividade. 

### Objetivos do projeto

* Praticar a conversão de layouts do Figma para código
* Desenvolver habilidades em HTML e CSS
* Trabalhar com organização de componentes e seções
* Aplicar conceitos de design responsivo

### Tecnologias utilizadas 

* HTML5
* CSS3
* Figma (protótipo)

### Funcionalidades 

* Layout responsivo para diferentes tamanhos de tela
* Estrutura de navegação simples e intuitiva
* Seções institucionais (sobre, serviços, contato)
* Design moderno e focado em experiência do usuário

---

> Este projeto tem fins educacionais e não representa uma empresa real.
